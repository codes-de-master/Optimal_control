# Optimal Control Revision — Astro

Site de révision statique basé sur les notes et supports du cours d'Optimal Control 2026.

## Développement local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Le résultat statique est généré dans `dist/`.

## Déploiement Vercel

1. Importer ce repository dans Vercel.
2. Vercel détecte automatiquement Astro.
3. Build command: `npm run build`.
4. Output directory: `dist`.

Aucune variable d'environnement n'est nécessaire.
